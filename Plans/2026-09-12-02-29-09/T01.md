# T01 Platforma, build a přenosnost

## Chronologická syntéza

S01 §1 až §6 stanoví C++20/MSVC, CMake 3.28+, Ninja, statický CRT, CNG/WinHTTP/IP Helper a nativní Win32 bez nové knihovny, navrhuje i volitelný ARM64 preset. S03 §1 opakuje Windows implementaci s přenosným jádrem bez HWND/HANDLE. S06 N09/F02 vyžaduje lehkou nativní vrstvu. S07 problém 7 ruší umístění modelů v tray a určuje samostatné objekty existující phpvpn-core v core/presentation, DOM v core/config. S09 WP01 tuto hranici konkretizuje a vyžaduje modelové testy bez oken. S13 odstavec o kroku Server Secret potvrzuje budoucí přenos na macOS/Linux, nyní pouze Windows. Pozdější notes nevyžadují hotový port.

Konečný záměr: Windows je dodávaná platforma, čisté modely lze sdílet později. ARM64 preset není sám důkazem dodané podpory. Architektura nevyžaduje další knihovnu, framework ani GUI v service/CLI.

## Důkaz implementace

První průzkum: client/CMakeLists.txt má C++20, WIN32 fail, CMake 3.28, statický CRT a uvedené kompilátorové přepínače. CMakePresets.json obsahuje debug, release=RelWithDebInfo, asan a arm64-release. Následuje kontrola skutečného linkování a hlaviček.

client/src/CMakeLists.txt skutečně registruje contracts_document, contracts_model a password_key_model jako samostatné objekty statické phpvpn-core. client/apps/CMakeLists.txt odděluje service, CLI a tray a využívá systémové knihovny. Hlavičky core/presentation nemají Windows typy ani includes. Testy ContractsModel a PasswordKey jsou registrovány v běžném phpvpn-client-tests, nativní UI cíle jsou opt-in.

## Dopad na konstrukci testů

Současné modelové testy pokrývají funkcionalitu. Není nutné psát test zrcadlící CMake. Při realizaci ověřit sestavení core/service/CLI/tray v Debug a release a linkerové mapy service/CLI pro nepřitažení modelových objektů. Tato binární kontrola nebyla v tomto průzkumu spuštěna a existence statické knihovny ji nenahrazuje. Porty se netestují jako dodané. Rizikem je nechtěná Windows závislost v jádře a falešný distribuční slib.

Stav: uzavřeno. Není potřeba rozhodnutí pro dokumentování AMD64 a přenosných modelů.
