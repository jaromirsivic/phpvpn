# T13 ACL datového stromu a startup default

## Chronologie

S01 §20 požaduje chráněná data. S03 §5.5 výslovně uvádí SYSTEM/Administrators. S04 F01–F04 zachovává tuto politiku, rozlišuje nepovolený descriptor od API access failure, žádná oprava ACL ani restart na Yes. S05 §3 nahrazuje zákaz startup vytvoření: po bezpečné přípravě/recovery právě jeden create-if-missing, degradované IPC při chybě, žádný retry a Connect nic nevytváří. S14 výslovně potvrzuje startup default a tři metadata, neobsahuje rozšíření ACL pro Users.

## Důkazy a klasifikace

Startup implementován: `client/apps/service/service_host.cpp::ServiceRuntime::start` připraví backend, recover, ensureDefaultAtStartup a zpřístupní IPC i při storage/engine chybě. `config_store.cpp::ensureDefaultAtStartup` vytvoří pouze skutečně missing, zachová existující bajty všech jiných availability. operationalStatus blokuje provoz/publikaci při nevyřešené inicializaci. `wizard_ipc.cpp` má konkrétní directory security a administrátorskou radu. Tray neopravuje ACL.

**R06, hranice rozsahu:** současný client.md i kód popisují read-only přístup Users do celého datového stromu, včetně historických klíčů, a startup normalizaci hardlinků. Testy `test_config_files_win.cpp` tuto implementaci dokládají. V uvedených zdrojích nebylo dohledáno schválení změny ze SYSTEM/Administrators-only na Users read. S04 naopak ochranu výslovně zachovává. Nejde o důvod měnit kód ani odstraňovat dnešní text, ale nelze tuto změnu připsat historickým zdrojům. Před jakýmkoli zásahem do těchto již existujících normativních částí požádat o vyjasnění, případně doplnění autoritativního zdroje koordinátorem.

## Dopad na cílovou dokumentaci

client.md ponechat aktuálně správný startup/create-only/degraded contract. Propojit error nápravu s tím, že restart může již sám vytvořit missing default a přeruší VPN. Nevracet staré tvrzení, že restart nic nevytváří. ACL text bez rozhodnutí R06 neměnit ani nerozšiřovat. protocol.md beze změny. tray_UX.md Edit Config Yes/No a directory error ponechat, bez administrátorských vedlejších účinků.

Existující `test_default_config.cpp`, `test_plan3_fix2.cpp`, `test_runtime_status.cpp::wizard_service.fix2_*`, NTFS startup_recovery_preserves_bytes_and_recreates_only_missing, changed_directory_acl_blocks_create_until_explicit_administrator_repair a descriptor_api_failure_is_not_a_policy_mismatch pokrývají startup a chyby. Částečně runtime end-to-end Edit Config → Yes závisí na skutečném běhu ACL testů. Doplnit pouze chybějící akceptační průchod po delete za běhu, No a concurrent create, pokud stávající UI/service fixture tyto větve neprovádí. Ověřit skutečný obsah, nikoli jen ack. Rozšíření read-only ACL má existující testy, ale není nová práce v tomto zdrojovém rozsahu do R06. NOT RUN nepovažovat za PASS. Zde nic neběželo.
