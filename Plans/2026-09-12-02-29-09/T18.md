# T18 Menu, singleton oken a nezávislý Disconnect

## Chronologie

S01 §17 a S02 §5/§8 definují tray jako IPC klienta. S03 §5.4 a D21 přidávají Wizard/Contracts, jedinou kontrolu po akci a nezávislý Disconnect během Show Info. S06 N01–N03, S07 problémy 1–5 a S09 WP02/WP05 zpřesňují nemodální souběh a jediné get-config-document pro Contracts. S10 žádá Statistics pod Connect, S13 jiné původní seskupení menu. Tyto historické pořadové varianty je nutné vést jako R07, nikoli mechanicky kombinovat.

## Důkazy a klasifikace

`client/apps/tray/menu_model.h` určuje Connect, oddělovač, Wizard, Contracts, Edit Config, oddělovač, Show Server Info, Statistics, oddělovač, Exit. `tray_application.cpp` používá samostatné status/config/command/disconnect/info čtečky. StartConfigAction reaktivuje existující editor/Contracts bez čtení, nová Contracts akce čte jediné get-config-document, Statistics get-config-state. Menu nečte disk ani konfiguraci a běžný timer čte status. Windows jsou samostatné koncepty a neblokují si používání, modelová pravidla limitují konkrétní operace. Implementováno.

## Dopad na cílovou dokumentaci

client.md a tray_UX.md zachovat autoritu stávajícího menu a pravidlo akčního čtení, žádné nové příkazy. Je-li při finálním průchodu nalezena stará dvojice get-config-state+document pro Contracts, nahradit jedním document podle S06/S07/S09. Samotné pořadí menu s rozpornou pozdější diktovanou variantou neřešit bez R07. protocol.md beze změny.

## Dopad na konstrukci testů

`test_tray_application.cpp`, `test_wizard_model.cpp`, `test_wp03_windows.cpp`, `test_wp05_windows.cpp` a UI runner pokrývají seam, izolaci a okna. Službová dostupnost je T10. Doplnit pouze chybějící skutečný tray scénář pomalé Show Info → Disconnect, s ověřeným doručením a viditelným výsledkem, protože existence oddělených členů sama nedokládá cestu od menu až k pipe. Ověřit nulové config čtení při timer/menu a reaktivaci dirty Contracts, pokud dosavadní fixture nepočítá volání. Pokrytí je mezi modely a integrací dílčí, rozsah má být několik rizikových akcí, nikoli další obecná UI suite. Zde testy neběžely.

Stav: uzavřeno s vazbou na R07.
