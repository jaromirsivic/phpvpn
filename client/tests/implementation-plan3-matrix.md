## Reprodukce a otevřená integrační brána

- Běžné testy používají projektové Debug/Release/ASan postupy z `client/tools/build-x64.ps1` a hlavního reportu. Zde nejsou nově spuštěny.
- Privilegovaný file běh má samostatný doložený log E-FILE. Bez elevace se jeho 10 admin-gated větví nesmí vykazovat jako provedené.
- Skutečný contract: `client/tools/run-server-contract.ps1`, explicitní opt-in target, server musí běžet. Nesmí být nahrazen fake PASS.
- Skutečné UI: `client/tools/run-tray-ui-tests.ps1`, případně `-Filter` nebo `-Interactive`. Podrobnosti a bezpečný rozsah v [ui/README.md](ui/README.md). Běh není součástí unattended CTest.
- Skutečný izolovaný SCM/Wintun E2E: [run-service-e2e.ps1](../tools/run-service-e2e.ps1), opt-in target a bezpečnostní podmínky v [e2e/README.md](e2e/README.md). E-E2E dokládá skutečný start/stop/restart, obousměrné UDP, pád a ownership recovery, nepředstírá čistou instalaci ani celý tray main.
- Čistá VM instalace/upgrade/uninstall, multiuser, sleep/resume, skutečné DPI 125/200 %, úplná cross-monitor kontrola a fyzický power loss zůstávají **NOT RUN**. Náhodný contention test v Python sadě zůstává SKIP, nový deterministický contention 503 je PASS. DNS a RSS maximálního IPC jsou PASS. Celá širší brána B19 není blanket PASS.
- Finální Debug/Release/ASan 215/0, UI 7/7, C++ contract 3/3, PHP 486 PASS, plná Python sada 386 PASS / 1 SKIP, skutečný E-E2E a znovu vytvořená distribuce po všech změnách jsou doložené výše. Dílčí screenshot QA je E-VISUAL, nelze jej rozšířit na neprovedené DPI a kroky. Celkový integrační verdikt vlastní hlavní report.
